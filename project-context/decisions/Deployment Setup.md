# Deployment Setup

The VitalNotes app is now connected through the first clean deployment pipeline.

## Current Pipeline

- Local development: VS Code and PowerShell
- App framework: Vite + React + TypeScript
- Repository: GitHub
- Hosting: Vercel

## Current Status

The app successfully runs locally.

The app successfully builds with:

npm run build

The app has been pushed to GitHub.

The app has been connected to Vercel.

The deployed app currently shows the temporary VitalNotes React checkpoint page.

## Important Boundaries

This deployment does not represent the final app interface.

It only confirms the app pipeline works.

The next phase is to build the first content model for the approved vertical slice.

Do not add dashboards, accounts, quizzes, simulations, AI features, Anki integration, progress tracking, or app bloat.

The first slice remains a calm, content-driven reader app.
