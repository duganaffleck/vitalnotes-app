# VitalNotes Project Context

This folder contains curated source-of-truth material copied from the VitalNotes Obsidian vault.

The Obsidian vault remains the true source of truth.

This folder exists only to give the app build and AI coding assistant stable local context.

Do not treat these files as student-facing app content.

Do not render these files directly.

Student-facing content should be manually modelled into:

- src/content/sections.js
- src/content/learningPath.js
- src/content/tools.js
- src/content/glossary.js

The first app slice is bounded.

Do not add dashboards, accounts, quizzes, simulations, Anki integration, AI feedback, or progress tracking.
