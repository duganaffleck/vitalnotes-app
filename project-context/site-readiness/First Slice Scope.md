# First Slice Scope

The VitalNotes app-readiness checkpoint is complete.

The first vertical slice is approved.

The app should now move into bounded implementation.

## Included in First Slice

- Home page
- Learning Path page
- Section Reader page
- Tools Library page
- Glossary page
- previous and next navigation
- related sections
- simple glossary support
- simple tool support

## Included Content Clusters

- 00 Start Here
- 01 Why Learning Feels Hard
- 02 Build Understanding
- 03 Build Usable Notes
- 04 Build Recall

## Active Tools

Only these tools are active:

- Directive Meaning Check
- Smart Note Template
- Clinical Recall Prompt Builder

## Excluded from First Slice

Do not build:

- accounts
- dashboards
- badges
- streaks
- scores
- quizzes
- simulations
- instructor dashboards
- LMS integration
- AI feedback
- AI reflection
- Anki integration
- deck management
- automated flashcard generation
- progress tracking
- analytics
- CMS
- MDX pipeline
- Obsidian import pipeline

## Build Philosophy

The app renders the guide.

The app does not reinvent the guide.

The writing is the main experience.

The UI should remain calm, readable, practical, and student-facing.
