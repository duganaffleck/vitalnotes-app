Key ideas to preserve:

- review feels good but retrieval builds access
- recognition is not the same as recall
- spacing strengthens delayed recall
- difficulty during recall is useful information
- study should reveal weak access before scenarios reveal it under pressure
- clinical recall should support assessment, prioritization, directive use, reassessment, and communication
- flashcards should support clinical access rather than flatten reasoning into isolated answers
- Anki can support retrieval and spacing, but should not become the learning system
- students need help turning facts, notes, scenario errors, and directive details into better recall prompts
