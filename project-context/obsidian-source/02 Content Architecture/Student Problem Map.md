# Student Problem Map

VitalNotes should be organized around the problems paramedic students actually experience.

This map supports [[Where to Begin]], app navigation, related section suggestions, and the broader [[New VitalNotes Learning Path]].

It should help students enter the guide through the problem they are actually having without turning VitalNotes into a quiz, diagnostic tool, advice generator, or personalized algorithm.

## Use in App Navigation

This map currently supports:

- [[Where to Begin]]
- [[Learning Path]]
- related section suggestions
- future problem-based navigation cards

It should not become:

- a quiz
- a diagnostic tool
- a personalized algorithm
- a replacement for reading the guide
- a complex onboarding process
- a progress dashboard
- an AI recommendation engine

The student should be able to recognize their problem quickly and choose a useful place to begin.
