# New VitalNotes Learning Path

The rebuilt VitalNotes path should be smaller, clearer, and easier to navigate than the original section list.

The path should move students from “I am struggling and I do not know why” toward “I have a way to study, think, practice, perform, and improve.”

Do not change this content map without an explicit decision.

---

## Current Review Question

Does this learning path move students from “I am struggling” toward “I know how to study, think, practice, perform, and improve” in a logical order?

Current answer:

Yes. The order is holding.

The current path moves through a useful progression:

1. orient the student
2. explain why learning feels hard
3. build understanding
4. build usable notes
5. build recall
6. think clinically
7. practice better
8. perform under pressure
9. reflect and improve

The next work should preserve this arc rather than reorganizing it.

## Current Path Assessment

The learning path is holding.

The current order creates a clean progression:

- students first understand what VitalNotes is
- then they understand why learning feels hard
- then they begin building meaning
- then they build notes that preserve and connect that meaning
- then they work on retrieval, clinical recall, and access
- then they move into clinical thinking, practice, performance, and reflection

This arc should be preserved.

The current first app slice is now strong enough to test the app interface because it includes orientation, learning difficulty, understanding, usable notes, recall, and three active tools.

The next content section, [[../03 Rebuilt Content/05 Think Clinically/Clinical Reasoning]], should shift the guide from “how knowledge becomes accessible” toward “how accessible knowledge is used when information is incomplete, changing, and sometimes misleading.”
