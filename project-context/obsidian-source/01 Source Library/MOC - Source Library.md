# MOC - Source Library

This folder tracks the material that informs the VitalNotes rebuild.

The source library is not meant to become student-facing content directly.

It is the quarry we draw from.

Source material should shape the guide quietly through better explanations, stronger examples, cleaner structure, and more useful student-facing tools.

It should not control the app structure or force the old site order to remain.

## Rule for Using Sources

Use sources implicitly and practically.

VitalNotes should not become:

- a book report
- a citation catalogue
- an academic literature review
- a list of learning science concepts
- a summary of source texts
- a theory-first guide
- a source-driven app

Students should feel the influence through:

- clarity
- usefulness
- good instructional design
- better examples
- stronger explanations
- realistic paramedic context
- tools that help them act differently

The source should improve the student-facing guide without becoming visible scaffolding.

---

## How Sources Should Be Used

Use source material to:

- preserve strong ideas from earlier VitalNotes drafts
- deepen explanations where sections feel thin
- reduce repetition where old material overlaps
- strengthen paramedic examples
- support learning science implicitly
- clarify concepts before they become glossary terms
- identify when a tool is genuinely earned
- protect the guide from generic study advice
- support future clusters such as [[05 Think Clinically]], [[06 Practice Better]], [[07 Perform Under Pressure]], and [[08 Reflect and Improve]]

Do not use source material to:

- add content just because it exists
- preserve old wording unnecessarily
- preserve old section order unnecessarily
- overfill student-facing sections
- name-drop books or authors in the guide unless explicitly requested
- create tools before repeated student need is clear
- expand the app during first-slice cleanup

## Working Rule

Sources inform the guide.

They do not become the guide.

When a source idea is useful, translate it into a student-facing learning problem, paramedic context, and practical implication.

If it cannot be connected to what students actually need to do, notice, understand, recall, practice, or improve, park it.
